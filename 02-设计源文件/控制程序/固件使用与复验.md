# 固件使用与复验

[Arduino 工程入口](SilkRoad/SilkRoad.ino) · [引脚表](SilkRoad/Hardware.h) · [调参区](SilkRoad/Settings.h) · [接线和上电顺序](../电路与接线/Nano接线与上电.md)

**编译。** 用 Arduino IDE 安装开发板包 Arduino AVR Boards 1.8.8、库 VL53L0X by Pololu 1.3.1，选择 Arduino Nano、ATmega328P。打开同名工程目录的 SilkRoad.ino，点“验证”。这是离线运行的小车，编译后无数据库、账号或网络依赖。已编译的无引导程序 HEX 在[固件导出](固件导出/)；推荐从源码编译以保持参数和实物同步。有些兼容 Nano 配旧 bootloader，烧录握手失败时选 ATmega328P (Old Bootloader)，先确认板型和端口。烧录由组员接板后进行。

有 Arduino CLI 的电脑可在本目录运行以下命令。依赖首次安装需网络。本机项目约定要求将下载、临时目录及构建缓存放在 E 盘时，先配置 CLI 的 directories.data、directories.user、directories.downloads 和 build_cache.path，指向自己的 E 盘工具目录。

~~~sh
arduino-cli core update-index
arduino-cli core install arduino:avr@1.8.8
arduino-cli lib install VL53L0X@1.3.1
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328 --warnings all SilkRoad
~~~

**模块分工。** Sensors.cpp 采集五路反射、保存带校验的两组标定值、依次唤醒测距器并更改地址。稳态轮询先查就绪位，单次 I²C 有超时；两侧各取三个独立测量的中位值。Drive.cpp 分别数左右轮槽边沿，以目标轮速和实测脉冲作闭环补偿。Race.cpp 决定起跑、循迹、搜线、选边、绕障、回线和停车。双侧近距离时，先停下，向两侧小角度转动并等候新测量；没有可行方向则锁车。绕行采用编码器限程，找到黑线中心后再前行一段探头至轮轴距离，才开始转正。跑动中不接受串口控制命令。

**台架调试。**

1. 先让车轮悬空。断电检查连线，再按电路说明分支上电。用 USB 串口，波特率设为 115200，发送问号读取五路 ADC、两侧毫米距离、fresh、标定状态、左右边沿和轮程。USB 仅用于台架；确认 USB 单独供电确实能给整条逻辑支路供电，马达电源仍断开。
2. 在调试台上把全部探头置于与赛道底色相近的均匀样面，按实际离地间隙发送 W。换同材质的足够宽黑色样面覆盖五个探头后发 B。检查返回 Calibration ready；再把真实宽度的黑线从左扫到右，五路读数应按顺序变化。课程黑线宽 \(20\,\mathrm{mm}\)，单根细线无法同时覆盖整排，不能用来做全黑采样。复位后再发问号确认标定已保存。每通道黑白差初始门槛为 \(100\) 个 ADC 计数。
3. 逐只手转轮子一整圈。预期对应一侧约 \(40\) 个边沿，另一侧不变。分别在两只测距板前放目标再移开，确认左右对应、fresh 稳定、空旷处能持续就绪。固件仅将指定的无回波哨兵解释为远处，断线／总线错误、测量过期及其他拒收状态会阻止起跑或锁车。必须用实际场地和深色、细小、斜面的模型检验漏检；调试不应用常数覆盖故障。
4. USB 拔下，车载电池上电，待两路测距就绪、标定有效且启动键已释放后短按。慢闪为就绪，运行时常亮；结束时常亮并制动，故障快闪并制动，须停机检查后复位。车轮仍架空时核对正转方向，单轮转反先断电调换该马达两线。D4 仅用于起跑，调试紧急停机用总开关。
5. 放车上测试黑线。先校左右轮距、轮径和每转边沿，调整电机死区与轮速补偿，再调循迹 PD；之后调侧移、绕行长度、入线角和停车滑行量。参数单位与符号见 Settings.h。单通道码盘只给出移动量，方向来自驱动命令，打滑和惯性需要实车复验。双测距默认平行安装，变更外倾角时一并更新 sensorAngleDeg 并重测盲区。
6. 在不同照明和电量下测停车。记录探头横排至车头的实际偏距、制动开始到静止的轮程，以及静止时车头／车尾相对终点线位置。以车头越线、车尾仍未越线为验收条件。正式运行只按一次启动，无线遥控和场外标记不属于本设计。

**本机回归。** 两个 C++ 程序直接链接实际固件的 Race.cpp。前者逐状态注入输入，后者计算差速车姿态、射线与障碍的距离、五个探头对赛道的采样和整车矩形碰撞。示例命令在当前目录执行；在 MSVC 开发者命令行可将编译器换为 cl 并启用 /EHsc /std:c++14 /utf-8，保持断言启用。

~~~sh
g++ -std=c++14 -Wall -Wextra SilkRoad/Race.cpp tests/race_test.cpp -o race_test
./race_test
g++ -std=c++14 -Wall -Wextra SilkRoad/Race.cpp tests/course_model.cpp -o course_model
./course_model
~~~

二维场景包含八个直线单障摆位，以及两条左右次序相反的缓弯连续四障路线。模型采用理想轮速、两束理想测距及几何探头，尚需在真实广告布曲线、环境光、光电门和不同电量下检验。台架检查和全场验收见[小组清单](../../小组实施与验收.md)。
