《工程创新训练Ⅱ》分散实训的小组资料仓库，按实物展示、设计、加工、演讲和成本分类保存项目成果。

目前已建好目录与填写模板。组员把真实资料放到对应位置，并更新相关索引；模板中的“待填”和未勾选项表示尚未完成。

## 快速开始

1. 先阅读 [上传与协作说明](CONTRIBUTING.md)。
2. 点开对应目录，再使用 GitHub 的 **Add file → Upload files** 上传文件。
3. 上传后更新该目录的资料索引或记录表，让大家能找到当前使用的版本。
4. 阶段结束时核对 [交付检查清单](CHECKLIST.md)。

直接提交需要仓库写入权限；尚未添加为协作者的组员可先 Fork，在自己的副本上传后发起 Pull Request。当前暂不添加协作者，后续由仓库维护者统一添加。

## 整理约定

- 文件名使用“日期_模块_内容_版本”，例如 `20261114_车架_底板设计_v01.SLDPRT`。同一版设计、照片、加工记录和测试记录使用一致的版本标识。
- 原生设计源文件与通用导出文件一起保留；PPT保留可编辑稿与演示导出。
- 每项资料优先保存在一个位置，其他页面通过相对链接引用。
- 失败试验也可记录，写明问题、改动和实际结果；不要把待验证内容写成已完成。
- 本仓库公开：上传项目成果与已脱敏的成本记录。完整发票、订单、联系方式、账号凭据等保存在小组私有位置。
