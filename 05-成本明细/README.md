# 成本明细

设计审阅见 [Nano 采购清单](Nano采购清单.md)。下单前核到手总额，成交后将实际金额填入成本明细。

| 位置 | 内容 |
| --- | --- |
| [成本明细表](成本明细.md) | 零部件与材料的用途、来源、数量、价格、实际成本和汇总 |
| [采购照片](采购照片/) | 与明细条目对应的物品照片、已脱敏凭证 |

购入或领用后更新明细，购买、自备和借用分开标明；没有确定的价格填写“待核实”，不要用空白或未经说明的零价代替。

项目成本记录完整用料与支出，报销是否符合要求另行核验。原始发票、支付记录及报销个人信息放在小组私有位置；公开仓库仅保留脱敏资料和凭证状态。
